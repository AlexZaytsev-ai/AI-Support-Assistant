# AI Lead Intelligence System

AI-система автоматической обработки B2B-лидов, разработанная на **n8n**. Workflow автоматически обогащает данные о компании, квалифицирует лид с помощью AI, сохраняет структурированную информацию и мгновенно уведомляет отдел продаж.

---

# Бизнес-проблема

Отделы продаж часто получают неполные или недостаточно квалифицированные лиды с сайтов, лендингов и контактных форм.

Перед тем как связаться с потенциальным клиентом, менеджеру необходимо:

- определить компанию;
- проверить её существование;
- собрать информацию о компании;
- понять потребность клиента;
- оценить качество лида;
- сохранить информацию в CRM;
- уведомить отдел продаж.

Эти повторяющиеся действия занимают много времени и замедляют обработку новых обращений.

---

# Целевая аудитория

- Отделы продаж

- Владельцы бизнеса

---

# Решение

Workflow автоматически обрабатывает каждый входящий лид.

Он:

- получает лид через Webhook;
- обогащает данные о компании через DaData API;
- проверяет корректность бизнес-данных;
- ищет компанию во внутреннем реестре;
- при необходимости создаёт новую запись компании;
- подготавливает структурированный контекст для AI;
- квалифицирует лид с помощью LLM;
- сохраняет результаты в Google Sheets;
- мгновенно уведомляет менеджера по продажам через Telegram.

# Архитектура Workflow

Полный workflow, разработанный в n8n, включающий проверку данных, обогащение информации о компании, AI-квалификацию лида, сохранение данных и уведомление менеджера.

## Демонстрация

### API-запрос

Новый лид отправляется в систему через HTTP POST-запрос с использованием Bruno.

![API Request](bruno-request.jpg)

---

### AI-квалификация лида

AI анализирует входящий лид, определяет потребность клиента, оценивает качество лида, назначает приоритет и формирует структурированное описание.

![AI Lead Qualification](ai-analysis.jpg)

---

### Реестр лидов

Обработанный лид автоматически сохраняется в Google Sheets как структурированная CRM-запись.

![Lead Repository](lead-repository.jpg)

---

### Уведомление в Telegram

Менеджер по продажам мгновенно получает структурированное уведомление с результатами анализа лида.

![Telegram Notification](telegram-notification.jpg)
