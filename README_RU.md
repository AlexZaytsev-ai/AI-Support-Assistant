# AI Support Assistant

AI-система автоматизации службы поддержки, разработанная на **n8n**. Workflow автоматически анализирует обращения клиентов, классифицирует их с помощью AI, сохраняет обращения в Google Sheets и направляет уведомления в соответствующий отдел.

![Workflow](workflow.png)

AI-автоматизация обработки обращений клиентов, построенная на платформе n8n.

---

# Бизнес-проблема

Сотрудники службы поддержки ежедневно тратят много времени на чтение, классификацию и перенаправление входящих обращений.

Это увеличивает время ответа клиентам, повышает вероятность ошибок при маршрутизации запросов и затрудняет контроль обработки обращений.

---

# Обзор решения

Workflow автоматически:

- получает обращения клиентов из Telegram;
- анализирует текст сообщения;
- классифицирует обращение с помощью AI;
- извлекает ключевые данные;
- формирует структурированный JSON;
- сохраняет обращение в Google Sheets;
- направляет уведомление в соответствующий отдел.
